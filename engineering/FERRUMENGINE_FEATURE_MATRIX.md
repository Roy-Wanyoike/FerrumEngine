## Status Legend

| Symbol | Meaning | Criteria |
|--------|----------|----------|
| 🟢 COMPLETE | Implemented AND tested | Code exists, tests pass, feature works end-to-end |
| 🟡 PARTIAL | Some code exists but incomplete | Related code exists, but the claimed feature is incomplete, misleading, or non-functional |
| 🟠 PENDING | Claimed but zero code | Referenced as planned/claimed but no implementation exists |
| 🔴 NOT IMPLEMENTED | Claimed as existing but no code | Marketed as "Stable" or "Beta" with zero implementation |
| ⚫ INTENTIONALLY DEPRECATED | Removed for good reason | Code was removed with documented rationale |
