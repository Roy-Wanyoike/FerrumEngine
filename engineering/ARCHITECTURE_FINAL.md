## Module Details

### 1. Ferrum Runtime (`src/lib/ferrum-runtime/`)

**Purpose**: Core execution layer for managing effect lifecycles on DOM elements.

| File | Responsibility |
|------|---------------|
| `index.ts` | Public API — `FerrumRuntime` class, `createEffect()`, `createObserver()` |
| `types.ts` | TypeScript interfaces — `FerrumEffect`, `FerrumConfig`, `ObserverConfig` |
| `observer.ts` | `ViewportObserver` — IntersectionObserver wrapper for enter/leave effects |
| `utils.ts` | `DOMObserver`, `TokenResolver`, `CSSExecutor` — DOM manipulation and token resolution |
| `reduced-motion.ts` | `ReducedMotionManager` — respects `prefers-reduced-motion`, enables/disables animations globally |

**Key Design Decisions**:
- Zero external dependencies
- Effect lifecycle: `created → mounted → active → unmounted → destroyed`
- Viewport observer with configurable `rootMargin` and `threshold`
- Reduced motion support via `matchMedia('(prefers-reduced-motion: reduce)')`

**Tests**: 21 tests in `__tests__/ferrum-runtime.test.ts`

### 2. Ferrum Motion (`src/lib/ferrum-motion/`)

**Purpose**: Physics-based and timeline-based animation system.

| File | Responsibility |
|------|---------------|
| `spring.ts` | Spring physics solver — semi-implicit Euler integration, configurable tension/friction/mass/bounce |
| `timeline.ts` | Timeline composer — keyframe sequencing with cubic Hermite interpolation, parallel/sequential modes |
| `scroll.ts` | Scroll-driven animations — IntersectionObserver triggers, scroll velocity tracking |
| `stagger.ts` | Stagger engine — configurable delay distribution across element lists |
| `decay.ts` | Decay animation — velocity-based deceleration with configurable friction |
| `types.ts` | TypeScript interfaces — `SpringConfig`, `TimelineKeyframe`, `ScrollConfig` |
| `reduced-motion.ts` | Motion-aware reduced motion — disables spring/scroll animations when OS preference is set |

**Key Design Decisions**:
- Spring solver uses semi-implicit Euler (not RK4) for performance — UI animations don't need orbital mechanics accuracy
- Timeline supports both parallel (`timeline.parallel()`) and sequential (`timeline.sequence()`) composition
- All modules respect reduced-motion media query
- Configurable precision for spring settling detection (default: 0.01)

**Tests**: 23 tests in `__tests__/ferrum-motion.test.ts`

### 3. Ferrum VFX (`src/lib/ferrum-vfx/`)

**Purpose**: Visual effects system for particles, glass morphism, gradients, cursor effects, and distortion.

| File | Responsibility |
|------|---------------|
| `particles.ts` | Canvas-based particle emitter — configurable emission rate, velocity, color, size, lifetime, gravity |
| `glass.ts` | Glass morphism — `backdrop-filter` blur, transparency, border highlight, configurable blur radius |
| `gradient.ts` | Dynamic gradient generation — radial/linear/conic modes, animated color stops, mesh gradients |
| `cursor.ts` | Cursor glow — mouse-tracking radial glow effect, configurable size/color/opacity/intensity |
| `distortion.ts` | CSS distortion — wave, ripple, and noise effects via CSS filters and SVG filters |
| `types.ts` | TypeScript interfaces — `ParticleConfig`, `GlassConfig`, `GradientConfig`, `CursorConfig` |
| `index.ts` | Public API barrel — `createParticleEmitter()`, `createGlassEffect()`, `createGradient()`, `createCursorGlow()`, `createDistortion()` |

**Key Design Decisions**:
- Particles use HTML5 Canvas (not DOM) for performance — supports 1000+ simultaneous particles
- Glass morphism uses CSS `backdrop-filter` (widely supported, no WebGL needed)
- Distortion uses CSS/SVG filters (not WebGL/GLSL) for zero-dependency approach
- Cursor glow uses `requestAnimationFrame` with cleanup on unmount

**Tests**: 19 tests in `__tests__/ferrum-vfx.test.ts`

### 4. Ferrum Compiler (`src/lib/ferrum-compiler/`)

**Purpose**: CSS parser and 9-pass optimization pipeline.

| File | Responsibility |
|------|---------------|
| `parser.ts` | CSS parser — tokenizes CSS into rule AST (selectors, declarations, media queries, keyframes) |
| `optimizer.ts` | 9-pass optimizer — analyze → DCE → inline → merge → compress → minify → validate |
| `generator.ts` | CSS generator — serializes AST back to CSS string, supports pretty-print and minified modes |
| `browsers.ts` | Browser compatibility — autoprefixer-like vendor prefixing, feature detection |
| `types.ts` | TypeScript interfaces — `CSSRule`, `CSSDeclaration`, `CSSAtRule`, `CompilerOptions` |
| `index.ts` | Public API — `compileCSS()`, `parseCSS()`, `optimizeCSS()` |

**9 Optimization Passes**:
1. **Analyze** — classifies rules, builds dependency graph
2. **DCE** — removes unused rules based on class reference analysis
3. **Inline** — inlines variables and simple computed values
4. **Merge** — merges duplicate selectors, combines declarations
5. **Compress** — shortens color values, units, shorthands
6. **Minify** — removes whitespace, comments, unnecessary semicolons
7. **Prefix** — adds vendor prefixes for target browsers
8. **Validate** — checks for syntax errors, invalid values
9. **Output** — generates final CSS string in requested format

**Tests**: 29 tests in `__tests__/ferrum-compiler.test.ts`

### 5. Ferrum Semantic Components (`src/components/ferrum/semantic/`)

**Purpose**: React components that integrate Ferrum CSS effects via an `effect` prop.

| Component | `effect` Prop | Description |
|-----------|:------------:|-------------|
| `FerrumButton` | ✅ | Button with hover/active/focus effects |
| `FerrumInput` | ✅ | Text input with focus/filled effects |
| `FerrumCard` | ✅ | Card container with hover/entrance effects |
| `FerrumBadge` | ✅ | Badge/tag with glow/pulse effects |
| `FerrumTooltip` | ✅ | Tooltip with fade/slide entrance effect |
| `FerrumAccordion` | ✅ | Accordion with expand/collapse effects |
| `FerrumToggle` | ✅ | Toggle switch with state-change effects |
| `FerrumSkeleton` | ✅ | Loading skeleton with shimmer effect |

**Key Design Decisions**:
- Each component accepts a standard `effect?: string` prop that maps to Ferrum CSS class names
- Components are thin wrappers — they don't re-implement shadcn/ui, they add effect capability
- All components forward refs for composability
- Accessible by default (ARIA attributes, keyboard navigation)

**Tests**: 25 tests in `__tests__/ferrum-semantic.test.tsx`

### 6. Framework Adapters (`src/adapters/`)

**Purpose**: Framework-specific utilities for applying Ferrum effects.

| Adapter | File | Key Exports |
|---------|------|-------------|
| React | `react.ts` | `useFerrumEffect()`, `useSpring()`, `FerrumProvider` |
| Vue | `vue.ts` | `useFerrumEffect()`, `useSpring()`, `v-ferrum` directive |
| Svelte | `svelte.ts` | `ferrumEffect()`, `springStore` action |
| Angular | `angular.ts` | `FerrumEffectDirective`, `SpringService` |
| Lit | `lit.ts` | `ferrumEffect()` decorator, `springController` |
| Vanilla | `vanilla.ts` | `applyEffect()`, `createSpring()`, `FerrumMount` class |

**Key Design Decisions**:
- Each adapter follows framework idioms (hooks for React/Vue, directives for Angular, actions for Svelte)
- Vanilla adapter is the reference implementation — zero framework dependencies
- Adapters wrap ferrum-runtime and ferrum-motion, not re-implement them

**Tests**: 14 tests in `__tests__/adapters.test.ts`

### 7. Ferrum Tokens (`src/lib/ferrum-tokens/`)

**Purpose**: Design token definitions with 5 output format transformers.

- **14 scales**: colors, spacing, radius, fontFamilies, fontSizes, fontWeights, lineHeights, letterSpacings, shadows, durations, easings, breakpoints, zIndex, opacity
- **5 formats**: CSS variables, Tailwind config, SCSS variables, JSON, TypeScript types
- **Build**: Dual output — `index.d.ts` (292 LOC, types) + `index.cjs` (822 LOC, runtime values)

### 8. Showcase Website (`src/`)

**Purpose**: Next.js 16 SPA showcasing all FerrumEngine capabilities.

- **Framework**: Next.js 16 + Turbopack + TypeScript strict mode
- **Styling**: Tailwind CSS v4 + shadcn/ui (12 primitives)
- **Views**: 19 SPA views (homepage, effects gallery, playground, docs, blog, changelog, cloud, architecture, component catalog, pricing, etc.)
- **API**: 7 public endpoints + 12 cloud CRUD endpoints
- **Features**: Dark/light theme, global search (Cmd+K), color customizer, scroll progress, SPA routing
